This directory has code that handles the serial ports (i.e. UARTs).

sern.c is a general-purpose interrupting serial port 'n' driver.
There is one for each serial port.

-------------
Ver. History :
--------------
ver 1.00  - Initial release.


sern_poll.c is a general-purpose polling serial port 'n' driver.
There is one for each serial port.
