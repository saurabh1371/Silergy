This directory builds hex2c.exe, a windows tool to 
translate .hex files to .c files.

The utility is very generic "C" console code, but the project is for MSVC++ 2010.
hex2c_VS2010_proj\ - Microsoft Visual Express 2010 project for Hex2C.exe


hex2c usage:   hex2c array_name infile.hex outfile.c
hex2c example: hex2c Bootloader SY7T_M11_bootloader.hex Bootloader_Array.c
