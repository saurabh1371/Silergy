This is the source folder for a Silergy Meter Software Development Kit
\cm0 has shared code for a Cortex M0.
\drivers has the source code for some shared drivers.
\library has some generic library code useful for the demo code.
\sy*_<type><number> is a chip's private drivers and code.

clean.bat click on it to delete files produced by many editors and compilers.
