This directory has the header files for ARM's CMSIS.
The code has built-in definitions for both GNUCC and Keil's ARMCC.

+ core_cm0.h  is the include file to access basic Cortex M0 core registers.
+ core_cmFunc.h  is the include file to access basic Cortex M0 in-line fns.
+ core_cmInstr.h  is the include file to access basic Cortex M0 instructions.
