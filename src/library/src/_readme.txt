This directory has high-level reusable code for the ARM demo code.

+ afe calculates usable data from the analog front end (CE driver's) outputs.
+ cal is the calibration storage code.
+ cli_buf is code that multiplexes buffers for the command line interface.
+ crc is CCITT CRC-16 and CRC-32 code.
+ dst is daylight savings time and time-zone code.
+ hash makes a data-dependent byte from a string.
+ log logs events.
+ mmath is special math used by metering.
+ parity is the parity code.
+ reg  defines the meter's billing register data structures and functions.
+ serb is the serial code that implements binary serial I/O.
+ serc is the serial code that implements "cooked" serial (i.e. backspace, etc.)
+ sspi is the low-level slave SPI driver code.
+ stm is the software timer module code.
+ tamper is the tamper detection code.
+ time defines calendar logic for the real-time clock.
